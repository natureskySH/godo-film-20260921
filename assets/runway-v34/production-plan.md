# GODO V34 · 영상 제작 설계와 승인안

2026-09-28. 현재 상태: 기획·자료 검수 완료 후 생성 승인 대기. 이번 작업의 Runway 소모 크레딧 0. 이 문서의 길이·이동량은 연출 목표이며 AI가 정확한 수치로 실행한다고 보장하지 않는다.

## 1. 제작 목적과 이번 변경

한 인물이 작업을 준비하고, 연필과 색연필로 그림을 완성해 가는 짧은 브랜드 영상. 동일 얼굴·의상·작품·공간을 유지한다. 대사와 추가 자막은 없다. 책상은 매끈한 아이보리, 종이는 책상 위에 평평하게 놓고 인물이 바르게 읽는 방향을 유지한다. 사용 도구는 연필과 색연필뿐이다.

리듬: 차분한 인물 → 힘 있는 준비 → 짧은 드로잉 두 컷 → 가까운 채색 → 충분히 감상하는 작품 엔딩. 연필 굴리기/내려놓기는 제외한다.

기획의 기준은 이미지를 각각 잘 만드는 데서 끝나지 않는다. 샷 리스트(장면별 촬영 명세)에 동작 시작 상태·끝 상태, 화면 안 이동 방향, 초점, 다음 컷과의 연결, 사용할 길이를 명시한다. Adobe도 스토리보드 이후 상세 샷 리스트를 만들고 촬영 전에 동선과 카메라 구도를 정할 것을 권장한다. [샷 리스트](https://www.adobe.com/uk/creativecloud/video/discover/shot-list.html), [촬영 대본](https://www.adobe.com/creativecloud/video/discover/shooting-script.html)

## 2. 시간 설계 — 정지 이미지로 판단할 수 없는 항목

24fps 기준의 편집 초안이다. 아래 시간은 최종 편집에 사용할 구간이며, 저비용 모델의 원본 생성 길이 5초와 다르다. 동작을 무조건 배속하지 않고 필요한 구간만 짧게 선택한다.

| 샷 | 편집 구간 목표 | 동작의 시작→핵심→끝 | 카메라/초점 | 연결 |
|---|---:|---|---|---|
| S01 인물 | 약 2.4초 | 같은 우측 상단 시선 → 미세한 표정 → 같은 시선 | 고정, 눈 초점. 큰 웃음/숨 내쉬기 지양 | 약 6프레임 디졸브 |
| S02 매듭 | 약 2.2초 | 이미 잡은 끈 → 양옆으로 단호한 한 번의 당김 → 장력과 반동 정리 | 매듭 중앙 고정. 필요하면 편집 확대 최대 3% | 당김이 가라앉는 지점에서 다음 동작으로 |
| S03 첫 선 | 약 0.9초 | 이미 닿은 연필 → 짧은 선 하나 → 잠깐 정지 | 접촉점 고정, 초점 이동 없음 | 약 4프레임 이하의 짧은 시간 경과 전환 |
| S04 첫 색 | 약 1.2초 | 파란 심 접촉 → 작은 채색 1–2회 → 다음 동작 방향 확보 | 접촉점 매크로, 고정 노출 | S05와 같은 방향·위치의 동작 연결 |
| S05 부분 채색 | 약 3.0초 | 같은 색 영역과 손 방향 → 신중한 채색 → 손이 잠깐 멈춤 | 손·파란 물결을 크게. 안정적일 때 편집 확대 약 3% | 약 0.45초 그래픽 매치 디졸브 |
| S06 완성작 | 약 4.2초 | 작품 감상 → 중심 확대 → 부드러운 암전 | 편집 키프레임 100→108%, 중심 고정 | 마지막 1.1초 암전 |

합계 약 13.9초에서 전환의 겹침을 빼면 약 13초다. 예시 프레임 길이 58/53/22/29/72/101, 전환 겹침 6+4+11프레임이면 최종 314프레임, 약 13.08초. 실제 컷 위치는 결과물의 움직임을 보고 확정한다. 짧은 S03·S04 때문에 전체 길이를 인위적으로 20초 이상 늘리지 않는다.

### S02: 힘 있게 당기는 장면

- 손은 시작 이미지에서 이미 끈을 잡고 있다. 다시 잡거나 손가락을 복잡하게 교차하지 않는다.
- 완성된 매듭 바로 옆의 허리끈을 양손으로 약 3–4cm씩 단호하게 한 번 당기는 인상. 뒤로 길게 잡아채거나 여러 차례 흔들지 않는다.
- 약 0.6초의 당김 후 0.4초 안팎으로 반동이 가라앉는다. 에너지는 팔꿈치의 짧은 이동, 원단의 주름과 장력에서 표현한다.
- 중앙 매듭은 조여져야 한다. 고리나 끈 끝을 잘못 당겨 매듭이 풀리는 결과, 끈이 늘어나거나 개수가 바뀌는 결과는 실패다.
- 실제 5초 원본에서는 앞뒤 정지 여유를 확보하고 약 2.2초만 사용한다. 아래 프롬프트는 동작 하나로 단순화하되 위 기준으로 검수한다.

### S04→S05: 갑작스러운 전경 전환 없애기

현재 S05는 위에서 넓게 내려다보며 머리·양손·작품 전체가 보인다. V34에서는 기존 이미지의 손과 파란 물결 주변을 확대해 구도 제안을 표시했다. **CSS 크롭 미리보기이며 새 시작 이미지가 생성된 것은 아니다.** 단순 크롭으로 화질과 종이 각도가 충분하지 않으면 시작 이미지를 별도 수정해야 한다.

실제 제작 기준:
- S04의 마지막 연필 접촉점과 S05의 첫 접촉점을 화면 중앙 부근의 비슷한 위치에 둔다(화면 폭·높이의 약 5% 이내 차이를 목표).
- 같은 손, 같은 파란색 심, 같은 파란 물결 영역, 같은 화면 진입 방향을 유지한다. 종이가 좌우 반전되거나 90도 돌아가면 실패.
- 카메라가 작업 축의 반대쪽으로 갑자기 넘어가지 않도록 한다. 확대 크기는 달라도 손이 진행하는 방향은 이어져야 한다.
- 부분 채색은 시간 경과가 있는 단계다. S04에서 S05로 작품 전체가 마법처럼 즉시 채워지는 연속 동작을 요청하지 않는다. 가까운 영역에서 같은 채색 동작을 이어 **시간을 생략한 연결**로 편집한다.
- 동작이 잘 맞으면 매치 온 액션(움직임을 이어 붙이는 컷)을 우선한다. 손이 안 맞는데 긴 디졸브로 덮으면 두 손이 겹치므로, 짧은 정지 지점에서 컷하거나 시작 구도를 다시 조정한다.

위 원칙은 연속성 편집의 동작 일치와 eye trace(관객이 보던 위치를 다음 화면에서도 이어 주기)를 적용한 것이다. [Adobe 연속성 편집](https://www.adobe.com/creativecloud/video/hub/ideas/what-is-continuity-editing-in-film.html), [매치 컷](https://www.adobe.com/creativecloud/video/discover/match-cut.html)

### S06: 작품만 확대하며 암전

- 기존 깨끗한 완성작 정지 이미지를 사용한다. 새로운 그림이나 글자를 생성하지 않는다.
- 약 4.2초 동안 100%에서 최대 108%로 중앙을 향해 확대한다. 이는 카메라가 실제로 앞으로 움직이며 원근이 바뀌는 dolly가 아니라 **디지털 푸시 인(편집 확대)**이다. 평평한 작품에는 이것이 더 예측 가능하다.
- ease-in/ease-out(시작과 끝을 완만하게 하는 속도 곡선)을 사용한다. 확대 중심을 이동하거나 종이를 회전시키지 않는다.
- 마지막 약 1.1초 동안 천천히 검정으로 사라진다. 학과 KOREA 글자가 감상 구간 동안 잘리지 않아야 한다.
- 홈페이지 반복 재생은 끝의 검정과 첫 장면의 짧은 페이드 인을 맞춘다. 검정이 지나치게 오래 머물거나 재시작이 번쩍이지 않게 확인한다.

## 3. 영상 전용 의사결정 목록

| 항목 | 이번 결정 | 실제 영상에서 확인할 것 |
|---|---|---|
| Blocking/동선 | 한 샷에 한 핵심 동작 | 손 진입·퇴장, 끈 장력, 연필 경로 |
| Anticipation/준비·follow-through/잔동작 | 매듭 컷에는 준비와 짧은 반동 포함 | 급발진·갑자기 멈춤·몸 전체 튕김 |
| Screen direction/화면 진행 방향 | S04·S05 손 방향과 작업 축 유지 | 컷 사이 좌우 뒤집힘 |
| 시간적 연속성 | 선→첫 색→부분 채색→완성의 시간 생략 | 채색이 연필과 무관하게 번짐 |
| 초점·피사계 심도 | 눈 또는 연필 접촉점에 고정 | 초점 펌핑(선명도가 반복 출렁임), 손톱만 선명해짐 |
| 카메라 속도·가감속 | 생성 카메라는 대부분 고정, 확대는 편집에서 제어 | 흔들림·궤도 이동·갑작스러운 확대 |
| 렌즈 느낌 | 인물은 망원 압축감, 손은 매크로. 수치는 연출 언어 | 왜곡·손 크기 변화·배경 원근 뒤틀림 |
| 모션 블러 | 24fps 자연스러운 움직임, 접촉점은 읽을 수 있게 | 잔상·중복 손가락·너무 날카로운 스텝 |
| 조명·노출·화이트밸런스 | 고정된 부드러운 자연광, 같은 벽 색 | 깜박임·색온도 변화·광원 방향 반전 |
| 질감의 시간적 일관성 | 피부/천/종이 무늬 고정 | 얼룩이 흐르거나 표면이 끓는 현상 |
| 시선·표정 | S01 동일 상단 우측 응시 | 카메라를 쳐다봄·비웃음·입 비대칭 증가 |
| 물리적 접촉 | 연필 끝과 종이, 손과 끈 접점 보존 | 관통·떠 있음·잡지 않은 물체가 움직임 |
| 편집 여유 | 생성 5초 중 앞뒤 정지 구간 확보 | 전환용 여유 프레임 부족 |
| 전환 방식 | 짧은 디졸브와 동작 일치 컷을 구간별 선택 | 손 잔상·점프·두 작품 겹침 |
| 속도 처리 | 기본 원속도, S03·S04는 짧게 자름 | 무작정 50% 감속·과도한 광학 흐름 보간 |
| 색보정 | 먼저 노출·화이트밸런스 일치, 이후 최소한의 룩 | 한 장면만 피부가 노랗거나 종이가 회색 |
| 사운드 | 홈페이지 기본 무음, 대사 없음 | 자동 생성된 말소리·불필요한 효과음 |
| 브랜드 | 인물·복장·작품 고정. 뒤 매듭 컷에는 정면 GODO가 안 보임 | 정면 로고를 억지로 뒤에 생성하지 않음 |
| 출력 | 16:9, 1280×720, 24fps, H.264/MP4, 웹 재생용 faststart | 프레임 누락·검정 깜박임·모바일 크롭 |
| 접근·표시 | 홈페이지에서는 playsinline/muted/autoplay 정책 준수 | 모바일에서 얼굴·작품 핵심이 잘림 |

현재 6장면에는 정면 앞치마 로고를 길게 보여주는 컷이 없다. 뒤 매듭 연출의 자연스러움을 우선하며, 홈페이지 헤더 로고는 유지한다. 영상 내부 정면 로고 노출을 추가하려면 별도 컷과 비용을 제안하고 승인받는다.

Runway의 카메라 용어는 카메라의 방향과 역할을 명확히 하는 데 사용하며, 실제 렌즈·셔터를 물리적으로 보장하는 설정으로 취급하지 않는다. [Runway 카메라 용어](https://help.runwayml.com/hc/en-us/articles/46749315925395-Camera-Terms-Prompts-Examples)

## 4. Runway 기능을 사용하는 기준

1. **Image to Video:** 기본 방식. 이미지가 인물·공간·조명을 고정하고 실제 실행 텍스트는 동작 중심으로 짧게 작성한다. 상세 JSON은 별도로 보관한다. 입력의 시각적 결함이 영상에서 강화될 수 있으므로 원본부터 검사한다. [공식 프롬프트 지침](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)
2. **References:** 캐릭터·공간·작품을 참고해 새 시작 이미지를 만들 때 후보. 이미지용 References와 영상 모델의 referenceImages는 서로 다른 기능이다. 저비용 Turbo 영상은 시작 이미지 1장 방식이므로 여러 참고 이미지를 직접 받는다고 가정하지 않는다. [이미지 References](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)
3. **시작·끝 프레임/Animate Frames:** 끝 구도까지 맞춰야 할 때 후보. 이번 저비용 영상 모델은 끝 프레임 입력을 지원하지 않는다. 다른 모델이나 웹 App으로 변경하면 별도 비용 확인·승인이 필요하다. 작품 엔딩 확대는 로컬 편집으로 정확히 제어 가능하므로 이 비용을 쓰지 않는다.
4. **Motion Sketch:** 방향을 그림으로 지시하는 웹 App 후보. 현재 플러그인에 전용 호출이 노출되어 있지 않으므로 플러그인만으로 같은 기능을 사용할 수 있다고 단정하지 않는다. 손과 새 선이 일치한다는 보장도 없다. 필요한 경우 UI 기능·비용을 확인한 뒤 별도 제안한다. [Apps 목록](https://help.runwayml.com/hc/en-us/articles/45570040112531-Creating-with-Apps)
5. **Act-Two/동작 참조:** 실제 연기 참조가 있을 때 후보. 공식 권장 입력은 얼굴이 계속 보이고 손이 시작부터 화면에 들어오는 형태다. 뒤돌아선 매듭·손만 나온 매크로에는 이 조건이 맞지 않아 이번 기본 경로에서 제외한다. [Act-Two](https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two)
6. **Multi-Shot:** 여러 장면을 한 번에 만들 수 있지만, 다른 채색 단계와 정확한 작품을 독립적으로 수정하기 어렵다. 이번에는 개별 컷의 통과 여부와 비용을 기록하는 방식을 선택한다.
7. **Aleph/Edit Studio:** 기존 영상의 특정 내용 변경에 적합한 후보. 원래 동작을 유지하는 편집 도구를 사용한다고 어색한 손동작이 정확하게 교정된다고 약속하지 않는다. 움직임 자체가 실패한 컷은 짧은 재생성이나 시작 자세 조정이 우선이다.
8. **Workflows:** 입력 이미지+동작 텍스트→영상 생성→결과 확인의 최소 구성. 확정 출력을 잠그고 필요한 생성 단계만 실행한다. 자동으로 전체 노드를 재실행하지 않는다. 추가 LLM·Stitch·업스케일 단계도 비용이 생길 수 있다. [공식 Workflows](https://help.runwayml.com/hc/en-us/articles/45763528999699-Introduction-to-Workflows)
9. **Seed:** 가능한 경우 고정하여 프롬프트 변경을 비교한다. 동일 인물이나 동일 결과를 보장하는 장치로 해석하지 않는다.
10. **Retime/프레임 보간/업스케일/HDR:** 기본 시험에서 제외. 원속도의 좋은 구간을 먼저 고른다. 업스케일은 틀린 선과 손을 복구하는 도구가 아니다. 홈페이지용 720p 무음 결과에 HDR·음악·음성 기능은 이번 목표상 필요하지 않다.

기능을 100% 모두 실행하는 것이 목표가 아니라, 적용 가능한 기능을 빠짐없이 검토하고 효과·비용·위험에 따라 선택한다. 실제 모델 결과와 계정별 UI 기능까지 사전 조사만으로 완전히 보장할 수는 없다.

## 5. 기존 워크플로우 검증 결과

기존 「GODO - 연필 동작 테스트 - 저비용 구성 초안」은 생성 노드 1개, 텍스트 1개, 중복 이미지 입력 2개, 연결 0개인 저장 초안이다. 플러그인의 무료 검증에서 `UNCONNECTED_REQUIRED_INPUT` 경고를 확인했다. 구조 JSON이 valid라는 응답과 실행에 필요한 이미지가 연결되어 있다는 것은 다르다.

동일 검증의 비용 예상은 25크레딧이었다. 실제 실행은 하지 않았다. 이 초안을 연결된 제작 워크플로우라고 보고하거나 전체 실행하지 않는다. 다음 단계에서는 선택한 시작 이미지와 프롬프트를 명시한 개별 생성 호출을 사용하거나, 공식 작성 규격을 확인하여 연결을 수정한 뒤 다시 검증해야 한다.

## 7. 승인 요청 가능한 최소 시험

**권장: S02 매듭 당김 1개를 720p, 5초로 한 번 생성. 예상 25크레딧.**

- 이유: 기존 깨끗한 시작 이미지가 있고, 이번에 새로 요구한 힘 있는 동작·끈 구조·당김 후 정지를 한 번에 확인할 수 있다.
- 입력: S02 앞치마 뒤 매듭 이미지 1장.
- 과정: 이미지 업로드 → 명시적 5초/720p 설정 → 생성 1회 → 완료 확인 → 원본 저장 → 동작·끈·워터마크 검수 → 약 2.2초 사용 구간 선정 → 보고.
- 출력: 원본 5초 MP4 1개, 검수 결과, 선정한 구간의 타임코드. 다른 컷·재생성은 포함하지 않는다.
- 예상 비용: 초당 5 × 5초 = 25. 5초 동작 검증 분량을 기준으로 선택한 저비용 안이다. 다른 모델의 더 짧은 최소 길이는 총액이 더 낮을 수 있으나 같은 분량·동작 검증은 아니다.
- 전체 저비용 생성 예상: 5개 움직이는 컷 × 25 = 125크레딧. 시험을 채택하면 나머지 4개는 100이다. S05 시작 이미지 수정, 실패 재시도, 업스케일, 다른 모델, 음향은 포함하지 않는다.
- 이전에 제시한 품질 우선 36크레딧 시험은 이번 요청에 따라 보류한다. 이번에는 저비용 시험부터 승인받는다.
- 요금 근거: [공식 요금표](https://academy.runwayml.com/models-pricing), [5/10초 저비용 영상 설정](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4-Video). 실행 직전 계정과 설정을 다시 확인하고 승인 범위만 실행한다.

### 통과 기준과 중단 규칙

전후 정지 상태를 포함한 정상 속도 재생으로 먼저 판단하고, 손·끈·연필 접점은 프레임별 확대 검수한다. 구조 변화, 얼굴 변화, 선과 심의 불일치, 움직이는 얼룩, 워터마크가 있으면 해당 컷을 통과시키지 않는다. 추가 비용이 필요한 해결은 원인·수정안·예상 비용을 보고하고 다시 승인받는다. 저비용 시험 결과가 좋다고 상위 모델에서 같은 결과가 나온다고 보장하지 않는다.
